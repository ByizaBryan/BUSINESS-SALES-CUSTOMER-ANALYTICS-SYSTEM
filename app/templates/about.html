Relational Database Design (3NF)

The relational database schema is normalized to Third Normal Form (3NF) to eliminate update anomalies, ensure referential integrity, and optimize aggregation performance.

Table Primary Key Foreign Keys Core Purpose
CATEGORIES category_id — Merchandise department grouping
SUPPLIERS supplier_id — Vendor directory & procurement
PRODUCTS product_id category_id, supplier_id SKU pricing, costs, inventory stock
CUSTOMERS customer_id — Demographics & RFM loyalty tiers
STORES store_id — Retail branches & geographic regions
SALES sale_id customer_id, store_id Order headers, channels & tender
SALE_ITEMS sale_item_id sale_id, product_id Line item volume, price & discount
Business KPI Mathematical Formulations
1. Line Revenue:
Revenue = (Quantity × Unit Price) − Discount
2. Cost of Goods Sold (COGS):
Cost = Quantity × Unit Cost
3. Gross Profit:
Gross Profit = Revenue − Cost
4. Profit Margin Percentage:
Margin % = (Gross Profit / Revenue) × 100
5. Average Order Value (AOV):
AOV = Total Revenue / Total Number of Orders
6. Month-over-Month (MoM) Growth:
MoM Growth % = ((Revenue_{t} − Revenue_{t-1}) / Revenue_{t-1}) × 100
Security & Dual-Environment Deployment
Application Security Controls:
  • No Hardcoded Credentials: All database credentials and secret keys are isolated in .env and excluded from version control via .gitignore.
  • SQL Injection Immunity: All database queries utilize parameterized prepared statements (e.g. %s / ?), eliminating query concatenation risks.
  • Safe Error Handling: Stack traces and database internals are shielded from client API responses.
  • HTTP Security Headers: Incorporates nosniff, SAMEORIGIN, and XSS protection.
Cloud Production Readiness:
  • Dual-Engine Compatibility: The backend seamlessly supports MySQL (Aiven, PlanetScale, Railway) and local SQLite fallback.
  • Environment Switching: Transitioning from development to production requires only setting DB_HOST and DB_PASSWORD in cloud environment variables.
  • WSGI Deployment: Pre-configured for high-throughput WSGI servers (gunicorn for Linux/Docker, waitress for Windows).
